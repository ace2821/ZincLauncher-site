.desktop file

Desktop entry for KDE / GNOME / Xfce menus. Use this if launcher integration doesn't work automatically. Place it in ~/.local/share/applications/ and adjust the Exec path to your AppImage location.

zinc-launcher.desktop
Download .desktop 
# Install to applications menu
cp zinc-launcher.desktop ~/.local/share/applications/
update-desktop-database ~/.local/share/applications/
Prefer GitHub Releases? The same files are also published on GitHub Releases. Direct downloads here are a convenience mirror.

Install after download

# 1. Make the AppImage executable
chmod +x "Zinc-Launcher-1.2.6-x86_64.AppImage"

# 2. Run it
./"Zinc-Launcher-1.2.6-x86_64.AppImage"

# 3. (Optional) Install .desktop for menu integration
cp zinc-launcher.desktop ~/.local/share/applications/
update-desktop-database ~/.local/share/applications/

Release notes

1.2.6 latest

What's new in 1.2.6

  • Big Picture w stylu PS5 — nowy layout z sekcją modów.
  • Statystyki czasu gry — podsumowanie sesji i łącznego czasu.
  • Okładki Big Picture — dedykowane okładki oraz automatyczne pobieranie.
  • Poprawki modów — WorldBox i NeoModLoader.
  • Pełny rebrand na Zinc — nowa nazwa, ikona i identyfikatory.

1.2.0

  • Addon Marketplace — motywy i addony dostępne bezpośrednio w launcherze.
  • Wykrywanie konfliktów modów — ostrzega o nakładających się plikach (overlapping files).
  • Marketplace w launcherze — przeglądanie i instalacja jednym kliknięciem.
  • Deep-link zinclauncher:// — instalacja addonów bezpośrednio ze strony.

1.1.0

  • Rozszerzony katalog mod loaderów (NeoModLoader, tModLoader, CLEO, Script Hook, Frosty, MSC).
  • Adaptery klientów multiplayer: SA-MP / FiveM / MTA.
  • Przygotowanie pod Flathub: manifest, AppStream metainfo, ikona aplikacji.
  • Tray z graceful degradation bez libappindicator.

0.1.0

  • Pierwsze publiczne wydanie.
  • Big Picture (Xbox / PlayStation), okładki Steam, BepInEx / MelonLoader.
  • GameMode + MangoHud, licznik czasu gry, prefiksy Wine, interfejs EN / PL.
